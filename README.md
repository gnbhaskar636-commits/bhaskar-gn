## 💻 How to Run Locally (On Your Computer)

### 1. Prerequisites
*   Install **Node.js** (Version 18+) from [nodejs.org](https://nodejs.org/).

### 2. Setup
1.  **Download** the project code from AI Studio (Settings > Download ZIP).
2.  **Extract** the ZIP folder.
3.  Open your terminal inside that folder and run:
    ```bash
    npm install
    ```

### 3. Environment Variables
Create a file named `.env` in the root folder and add your Gemini API key:
```env
GEMINI_API_KEY="your_key_here"
APP_URL="http://localhost:3000"
```

### 4. Start the App
Run this command in your terminal:
```bash
npm run dev
```
Your app is now live at **http://localhost:3000**!

## ☁️ One-Click Deployment (GitHub)
1.  Go to **Settings > Export to GitHub** in AI Studio.
2.  Once in GitHub, click the **Code** button and select **Open with Codespaces**.
3.  GitHub will automatically set up the environment and run the app for you!
